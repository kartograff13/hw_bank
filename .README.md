# Краткое описание проекта 'hw_bank'

Проект разработан для IT-отдела крупного банка для личного кабинета клиента. Это виджет, который показывает несколько 
последних успешных банковских операций клиента.

## Подробное описание создания проекта
- Данный проект выполнен в ***Pycharm*** на языке-программирования ***Python***.
- Добавлено виртуальное окружение ***Poetry***. Все зависимости отображаются в *pyproject.toml*
- Добавлены конфигурации *flake8*, *mypy*, *black*, *isort*, а так же их параметры в *pyproject.toml* и в файл *.flake8*
- Созданы основные пакеты ***src*** — для исходного кода, ***tests*** — для тестов.
- В пакете ***src*** создан модуль ***masks***, в котором реализовано 2 функции:
1. Функция маскирует номер банковской карты *get_mask_card_number* :

Функция *get_mask_card_number* принимает на вход номер карты и возвращает ее маску. Номер карты замаскирован и 
отображается в формате XXXX XX** **** XXXX, где X — это цифра номера. То есть видны первые 6 цифр и последние 4 цифры, 
остальные символы отображаются звездочками, номер разбит по блокам по 4 цифры, разделенным пробелами.
```
7000792289606361     # входной аргумент
7000 79** **** 6361  # выход функции
```
2. Функция маскирует банковский счёт *get_mask_account* :

Функция *get_mask_account* принимает на вход номер счета и возвращает его маску. Номер счета замаскирован и отображается
в формате **XXXX, где X — это цифра номера. То есть видны только последние 4 цифры номера, а перед ними — две звездочки.

```
73654108430135874305  # входной аргумент
**4305  # выход функции
```

- Инициализирован локальный ***Git***-репозиторий в папке проекта через ***git init***
- Создан файл *.gitignore* в корне проекта и добавлен стандартный шаблон для ***Python*** для исключения системных и 
временных файлов
- В пакете ***src*** создан модуль ***widget***
- В модуле ***widget*** создана функция обработки информации карт и счетов *mask_account_card*, которая принимает один
аргумент содержащую тип и номер карты или счета, и возвращает строку с замаскированным номером.
Для карт и счетов используются разные маскировки благодаря импорту функций *get_mask_card_number* и *get_mask_account*
из модуля ***src/masks.py***

```
# Пример для карты
Visa Platinum 7000792289606361  # входной аргумент
Visa Platinum 7000 79** **** 6361  # выход функции

# Пример для счета
Счет 73654108430135874305  # входной аргумент
Счет **4305  # выход функции
```
Примеры входных данных для проверки функции:
```
Maestro 1596837868705199
Счет 64686473678894779589
MasterCard 7158300734726758
Счет 35383033474447895560
Visa Classic 6831982476737658
Visa Platinum 8990922113665229
Visa Gold 5999414228426353
Счет 73654108430135874305
```
- В модуле ***widget*** добавлена функция *get_date*, которая принимает на вход строку с датой в формате 
***"2024-03-11T02:26:18.671407"***
 и возвращает строку с датой в формате ***"ДД.ММ.ГГГГ" ("11.03.2024")***

у которых ключ state соответствует указанному значению.

```
Пример входных данных для работы функции:

отсортированный по дате (date).
```

## Установка и использование

1. Репозиторий, который создан как публичный на **GitHub**, любой человек может клонировать к себе на компьютер и начать 
работать с ним так, как будто это его личный репозиторий. Единственное ограничение — он не сможет запушить изменения, 
так как **GitHub** не дает напрямую менять чужие репозитории. 

Для работы с проектами нужно клонировать репозиторий к себе на компьютер с помощью команды `git clone`.
Полную команду для клонирования можно получить на странице репозитория. Для этого нажмите большую кнопку **Code**, 
перейдите на вкладку ***SSH*** и скопируйте содержимое:
```
git clone git@github.com:ТУТ_ВАШЕ_ГИТХАБ_ИМЯ/project.git
```
В процессе клонирования с помощью команды `git clone` автоматически создается удаленное подключение к исходному 
репозиторию. Такое соединение называется ***origin***.

Далее Вам необходимо выбрать настроенный у вас способ взаимодействия с **GitHub** (***HTTPS или SSH***) и скопировать 
ссылку на репозиторий для клонирования.

![Картинка для примера 4](https://cdn-user36618.skyeng.ru/skyconvert/unsafe/fit-in/684x/https://cdn-user12724.skyeng.ru/image/0f650eadcfd93b488c4be020c3b33c65.png)

- Вставьте ссылку на репозиторий и нажмите на кнопку ***Clone***:

![Картинка для примера 5](https://cdn-user36618.skyeng.ru/skyconvert/unsafe/fit-in/684x/https://cdn-user12724.skyeng.ru/image/e9792a85479ca9577900afec39eabfcc.png)

- По окончании клонирования будет открыт проект, Вы можете работать с этим проектом локально и отправлять свои коммиты 
в удаленный клонированный репозиторий.

При клонировании удаленного репозитория он будет изначально связан с исходным удаленным репозиторием. 
Отправлять его в другой пустой репозиторий не требуется.

3. После клонирования репозитория откройте терминал в PyCharm и перейдите в директорию проекта и выполните команду: 
```poetry install```.
- Эта команда создаст виртуальное окружение для проекта (если оно ещё не создано)
- Установит все зависимости, указанные в `pyproject.toml`
- Сгенерирует или обновит файл `poetry.lock`, фиксирующий версии зависимостей.

4. Используйте ```poetry run python script.py``` для запуска скрипта через терминал.
В **PyCharm** убедитесь, что в конфигурациях запуска (`Run` -> `Edit Configurations`) выбран правильный интерпретатор.
